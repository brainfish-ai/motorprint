Runs completely on-device in ~5.4 KB gzipped. No server, no LLM, no network calls.

Install bash 
npm install @brainfish-ai/motorprint
Vanilla JS / TypeScript ts 
import { createBotDetector } from '@brainfish-ai/motorprint';const detector = createBotDetector({  onScore: ({ score, isBot, windows }) => {    if (windows >= 4 && isBot) markSessionSuspicious(score);  },});
